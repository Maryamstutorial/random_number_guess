# 🎯 Number Guessing Game

A simple beginner-friendly Python game where the computer chooses a random number between **1 and 15**, and the player gets **3 chances** to guess it.

## 🎮 How It Works

* The computer randomly selects a number between 1 and 15.
* You have 3 chances to guess the number.
* If your guess is correct, you win! 🎉
* If your guess is too high, the game tells you.
* If your guess is too low, the game tells you.

## ✨ Features

* Random number generation
* 3 guessing attempts
* High and low hints
* Simple Python code

## 🛠️ Requirements

* Python 3

No extra libraries are required.

## ▶️ How to Run

Run the Python file in your terminal:

```bash
python your_file_name.py
```

Replace `your_file_name.py` with the name of your Python file.
